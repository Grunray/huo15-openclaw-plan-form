# demo 测试产物

本目录存放 skill 的实跑测试产物，供查看转换效果。

## 本次测试

- **源文件**：`用户文档/AI表单/AI表单/各客户需求表/马佳佩T+2周真单0227.xls`
  （园区 / 产业线 / 互联工厂 / 模块编码 / 项目 + `0227(周五)` 形式的日期列 + 合计）
- **判定**：客户需求排产表（`demand_schedule`），置信度 high
- **产物**：`客户需求排产表_20260227_*.xlsx`
  （文件名末段 `YYYYMMDD-HHMM` 为生成时刻，精确到分钟）

## 复现命令

```bash
F="用户文档/AI表单/AI表单/各客户需求表/马佳佩T+2周真单0227.xls"
python3 scripts/classify_form.py "$F"
python3 scripts/extract_form.py  "$F" --template demand_schedule --out /tmp/mjp.norm.json
python3 scripts/fill_template.py  /tmp/mjp.norm.json --out-dir demo/
```

## 转换结果要点

- 列映射：`园区→生产工厂`、`模块编码→客户料号`、`项目→规格型号`，9 个 `0227(周五)` 日期列正确解析为 ISO 日期并按 ISO 周分组（W09 / W10）。
- 28 行数据全部熔解填充；序号自动编号、合计自动 SUM 公式、模板示例数据已清除。
- 数据落点抽验一致：`0151801003A` 行 3/5=264、3/6=88，与源文件相符。

## 第二次测试：个人跟踪表

- **如何找到的**：用 `classify_form.py` 扫全部文件，判定为【计划跟踪跟单表 `plan_tracking`】的有三个，其中**唯一 high 置信度**的是 `计划跟踪--跟单个人表.xlsx`（领先 31.8），即"个人跟踪表"；客户文件里 `5月份计划更新0418 / 0425` 偏这类但只是 low（到货+库存混合）。
- **源文件**：`用户文档/AI表单/AI表单/计划跟踪--跟单个人表.xlsx`
  （1088号 / 客户 / 客户号 / 描述 + 代理库存·工厂库存·库存合计 + 月计划·已交·未交·结余·在制·总结余 + 欠料提示 + 月度预测 + 每日交付日期列）
- **判定**：计划跟踪跟单表（`plan_tracking`），置信度 high
- **产物**：`计划跟踪跟单表_20260420_*.xlsx`（7 行 × 47 列，含 26 个每日交付日期列）

### 复现命令

```bash
F="用户文档/AI表单/AI表单/计划跟踪--跟单个人表.xlsx"
python3 scripts/classify_form.py "$F"
python3 scripts/extract_form.py  "$F" --template plan_tracking --out /tmp/pt.norm.json
python3 scripts/fill_template.py  /tmp/pt.norm.json --out-dir demo/
```

### 转换结果要点

- 表头自动定位到第 2 行（跳过首行的无关数字）；`4月27日代理库存 / 工厂库存` 正确识别为**库存数值**而非日期列。
- `迷你图`（sparkline）列、重复的 `1088号2` 列被合理丢弃；月度多版本计划列择一保留。
- 数据落点抽验一致：`10880037199`（海信平度）代理库存=482、库存合计=482、欠料提示=暂不缺料；`10880037204` 月计划=1500、已交=1、未交=1499、欠料提示=5月23日、首天欠料=718，均与源文件相符。
