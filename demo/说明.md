# demo 测试产物

本目录存放 skill 的实跑测试产物，供查看转换效果。

## 本次测试

- **源文件**：`用户文档/AI表单/AI表单/各客户需求表/马佳佩T+2周真单0227.xls`
  （园区 / 产业线 / 互联工厂 / 模块编码 / 项目 + `0227(周五)` 形式的日期列 + 合计）
- **判定**：客户需求排产表（`demand_schedule`），置信度 high
- **产物**：`客户需求排产表_20260227_*.xlsx`
  （文件名末段 `YYYYMMDD-HHMM` 为生成时刻，精确到分钟）

## 复现命令

```bash
F="用户文档/AI表单/AI表单/各客户需求表/马佳佩T+2周真单0227.xls"
python3 scripts/classify_form.py "$F"
python3 scripts/extract_form.py  "$F" --template demand_schedule --out /tmp/mjp.norm.json
python3 scripts/fill_template.py  /tmp/mjp.norm.json --out-dir demo/
```

## 转换结果要点

- 列映射：`园区→生产工厂`、`模块编码→客户料号`、`项目→规格型号`，9 个 `0227(周五)` 日期列正确解析为 ISO 日期并按 ISO 周分组（W09 / W10）。
- 28 行数据全部熔解填充；序号自动编号、合计自动 SUM 公式、模板示例数据已清除。
- 数据落点抽验一致：`0151801003A` 行 3/5=264、3/6=88，与源文件相符。
